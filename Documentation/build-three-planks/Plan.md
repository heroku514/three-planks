# Plan - Three Planks

## Goal
Ship one small offline iOS app for kids, family, or seniors. A pretend gap stays on the phone. Both side planks go down before the middle. A side stays down while the middle is across.

## Approach
1. Confirm App Store Connect has no rejection waiting.
2. Build an Expo app with one screen and on-device storage.
3. Run the full simulator regression on the Release binary.
4. Take three real screenshots, upload that binary, and submit it.
5. Record the result and arm one next run.

## Stack
Expo SDK 57. The app is one screen and on-device storage, so JavaScript is enough.
